# Forum bug report template

Copy the block below into a new forum post and fill it in. Delete the hints in brackets as you go. It has the same fields as the GitHub form, so we can move your report over without asking you again.

One bug per post. Take personal stuff out of logs and screenshots first (real names, passwords, IP addresses, paths with your user name). Security bugs don't go on the forum at all; see SECURITY.md.

